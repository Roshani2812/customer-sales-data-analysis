# Customer Sales Data Analysis 📊

## Project Overview

This project analyzes customer sales data using Python and Pandas.

The goal is to clean the dataset, analyze sales performance, identify patterns, and generate useful business insights.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Google Colab

## Dataset

The dataset contains information about:

- Customer
- City
- Product
- Quantity
- Price
- Rating

A Sales column was created using:

Sales = Quantity × Price

## Data Cleaning

The following steps were performed:

- Checked dataset shape and structure
- Checked missing values
- Filled missing Customer values using Mode
- Filled missing Rating values using Median
- Checked for duplicate rows
- Created a new Sales column

## Analysis Performed

- Product-wise sales analysis
- City-wise sales analysis
- Customer-wise sales analysis
- City + Product analysis
- Average product ratings
- Quantity vs Sales correlation
- Data visualization

## Key Insights

- Laptop generated the highest revenue.
- Nashik had the highest total sales in this dataset.
- Laptop generated high sales in both Nashik and Pune.
- Mobile generated the highest sales in Mumbai.
- Quantity and Sales showed a negative correlation in this dataset.

## Project Workflow

CSV Dataset
→ Data Loading
→ Data Cleaning

→ GroupBy Analysis
→ Visualization
